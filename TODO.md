- **Email for invites (D-189)** — **grilled and spec'd 2026-08-10; ready to implement.** Three triggers only: direct session invite, direct poll invite, join-request approved (waitlist promotion was considered and rejected). One account setting, default on, email-only — in-app notifications unaffected.
  - **Escaping is load-bearing, not defensive**, because the owner chose to include notes. `EmbeddedEmailTemplateRenderer.cs:84` already HTML-encodes placeholders on the HTML arm, but `HtmlEncoder` makes a value safe as *text*, not inside an `href` — any template putting user content in or near a URL needs URL-context encoding. Subject lines have **no encoder at all**: reject CR/LF or a crafted title becomes header injection with an attacker-controlled `Bcc:`.
  - **Unsubscribe:** per-account CSPRNG token, stored hashed, never logged (A-015). The link opens a **confirmation page** and must not mutate on GET — mail scanners fetch every link in a message and would silently unsubscribe people. Acting on it disables the setting **and rotates the token**, killing forwarded or cached links. It can only disable; re-enabling requires signing in.
  - **Post-commit dispatch** on the shipped `IEmailDispatcher` path (A-016 keeps outbound side effects out of the invariant-holding transaction). A crash between commit and dispatch loses the mail; the in-app notification survives — the accepted trade.
  - Recipient's locale (D-060/D-146). Guests never receive it. Append new `EmailTemplate` enum members; the enum is dense and ordered, so do not renumber.
  - **Accepted leak, recorded in D-189:** notes leave the visibility engine permanently — a later privacy flip (D-047) or removal cannot recall a delivered email.
  - Setting renders normally for accounts with no email address (D-078 social-only), where it has no effect — owner's call.
  - **Out of scope, filed:** bounce and spam-complaint handling (provider webhooks + suppression list + its own spec row). Worth doing before volume grows — dead addresses damage the sending-domain reputation magic-link auth depends on.
